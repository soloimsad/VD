\section*{Visualización 2: Cuota de mercado redes sociales (2024)}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{images/radialbar.png}
    \caption{Fuente: Python (plotly) con datos de Kaggle (Social media popularity (2009 - 2025))}
\end{figure}

\begin{itemize}
  \item \textbf{Visualización:} Gráfico radial de barras (Radial Bar Chart)
  \item \textbf{Marca:} Participación promedio de plataformas sociales en 2024
  \item \textbf{Fuente de datos:} Social media popularity (2009 - 2025) (Kaggle)
  \item \textbf{Herramienta utilizada:} Python (pandas, plotly)
\end{itemize}

\subsubsection*{Canales Visuales}
\begin{itemize}
  \item \textbf{Color:} Canal categórico nominal que asigna un color distinto a cada plataforma social. No representa una escala cuantitativa, sino que sirve para diferenciación visual inmediata. Los colores están replicados en la leyenda junto a cada barra.
  \item \textbf{Posición:} Radial, donde cada plataforma ocupa una circunferencia concéntrica con un espacio constante entre líneas. La distancia al centro no representa valor, solo orden descendente según cuota.
  \item \textbf{Tamaño / Longitud::} La longitud del arco indica el porcentaje de cuota de mercado promedio. Cuotas mayores generan arcos más extensos.
  \item \textbf{Leyenda:} No se utilizó una leyenda separada. En su lugar, cada barra incorpora directamente el nombre de la plataforma y su valor porcentual, permitiendo una lectura directa e integrada.
\end{itemize}

\section*{Visualización 5: Flujos de ciberataques entre países (Tarea 3)}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{images/flujo_ataque.png}
    \caption{Fuente: Kepler.gl con datos del Cyber Events Database (UMD)}
\end{figure}

\begin{itemize}
  \item \textbf{Visualización:} Mapa de flujos mundial (Arc Layer)
  \item \textbf{Marca:} Conexiones visuales de ataques desde país origen hacia país víctima (2014–2024)
  \item \textbf{Fuente de datos:} Cyber Events Database 2014–2024 (dataset procesado para relaciones país–país)
  \item \textbf{Herramienta utilizada:} Kepler.gl (visualización), Python (procesamiento de datos)
\end{itemize}

\subsubsection*{Canales Visuales}
\begin{itemize}
  \item \textbf{Color:} El color se usa como canal categórico para distinguir el país atacante.
Cada arco toma un color distinto según su origen, permitiendo seguir visualmente las rutas desde múltiples actores simultáneamente.
No codifica magnitud ni orden, solo categoría nominal. Es útil para agrupar visualmente flujos con el mismo origen.
  \item \textbf{Posición:} Geográfica, basada en coordenadas reales (lat/lon) de cada país.
Los arcos respetan las distancias y proyección global del mapa.
  \item \textbf{Tamaño / Grosor (stroke):} Codifica la intensidad del flujo: a mayor número de ataques entre un par de países, más grueso el arco.
Canal cuantitativo clave para identificar actores principales.
  \item \textbf{Leyenda:} No hay leyenda visible de color, ya que los colores son nominales (solo distinguen países). El grosor se interpreta directamente por contraste visual.
\end{itemize}

\subsection*{Justificación de diseño visual}
\begin{itemize}
    \item \textbf{Visualización:} Gráfico de Flujo Tipo Sankey
    \item \textbf{Marca:} Visualización de Ciberataques según Tipo de Actor y Motivo.
    \item \textbf{Posición:} Eje horizontal para flujo entre categorías ("Tipo de actor" a "Motivo").
    \item \textbf{Herramienta utilizada:} Posiblemente Flourish, RAWGraphs o Tableau (basado en el estilo visual)
    \item \textbf{Color:} Diferenciación de tipos de actor.
\end{itemize}

\subsubsection*{Canales Visuales}
\begin{itemize}
  \item \textbf{Posición:} Eje horizontal para mostrar el flujo de relaciones entre categorías
  \item \textbf{Color:} Diferenciación de tipos de actor mediante colores únicos
  \item \textbf{Tamaño (grosor):} Representa el volumen de incidentes asociados a cada flujo
  \item \textbf{Conexión:} Enlace visual entre categorías (actor y motivo)
\end{itemize}
